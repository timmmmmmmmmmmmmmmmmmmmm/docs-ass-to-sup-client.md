# docs-ass-to-sup-client.md

## 目标 (Goals)
- 支持导入 ASS 字幕文件并正确渲染：字体、描边、阴影、渐变、旋转/缩放、动画、位移、打字机特效、卡拉 OK 等。
- 将渲染后的逐帧/逐事件字幕输出为 SUP (Blu-ray PGS) 位图字幕流。
- 在本地桌面端可视化预览与导出，离线工作。

## 客户端应用需求（Ass → Sup）
### 核心流程
1. **导入**：选择 .ass 文件与可选字体包（本地字体目录/zip）。
2. **解析**：解析脚本、样式、事件、时间轴、特效标签（包括覆盖标签）。
3. **渲染**：逐帧渲染到位图（支持多分辨率与帧率配置）。
4. **生成**：将位图与时间信息封装为 SUP/PGS。
5. **导出**：保存 .sup 文件，可选同时输出渲染日志与统计信息。

### 渲染与特效范围
- **基础排版**：字体、字号、颜色、描边、阴影、透明度、对齐、行距。
- **变换**：旋转、缩放、倾斜、位置偏移、锚点。
- **动画与特效**：`\t()` 动画、`\move` 位移、`\fade`/`\fad` 渐隐、打字机特效、卡拉 OK (`\k` 系列)。
- **层级与混合**：多行/多事件叠加、层级控制、透明叠加。
- **字体加载**：内嵌/外置字体发现与替换策略，缺失字体提示。

### 输出与质量
- **精确时间码**：帧精度对齐（支持自定义 FPS，例如 23.976/24/25/30/60）。
- **调色与位图优化**：抗锯齿、伽马校正、必要的颜色量化策略（与 PGS 兼容）。
- **多分辨率**：支持 720p/1080p/4K 渲染，分辨率与安全区可配置。

### 客户端界面（建议）
- **文件区**：导入 .ass、管理字体资源包。
- **预览区**：实时预览渲染结果，支持时间轴拖动与帧步进。
- **参数区**：分辨率、FPS、输出路径、调色策略、日志级别。
- **导出区**：一键导出 .sup，显示耗时与统计（事件数/帧数）。

### 可靠性与诊断
- **日志与报错**：对无法解析的标签、缺失字体、超出范围的样式给出提示。
- **渲染一致性**：尽可能与常见 ASS 渲染器表现一致（如 libass）。
- **性能**：支持批量渲染与进度反馈，长时间任务可取消。

## 交付建议（实现思路）
- **渲染引擎**：优先复用 libass 渲染逻辑或兼容实现，以确保特效一致性。
- **SUP 封装**：将每个事件/帧的位图与时间码打包为 PGS（SUP）结构。
- **桌面框架**：可选 Electron/Tauri/Qt，实现跨平台桌面端。

## 验收标准（示例）
- 导入带复杂特效的 .ass 字幕后，预览与主流播放器渲染视觉效果一致。
- 成功导出 .sup 并在 Blu-ray/PGS 兼容播放器中显示正常。
- 复杂字幕（大量事件/卡拉 OK）导出过程稳定，无崩溃。
